扫描不到设备？

在 NanoKVM 的 Settings → Device 中开启 mDNS。Unraid 容器使用 Host 网络；如果有多个网卡，可通过 MDNS_INTERFACES 指定 LAN 的 IPv4 地址。

同一 mDNS 主机名的有线与无线地址会合并。两台不同设备请设置不同的主机名。

面板只读取设备网页来检查状态，不保存 NanoKVM 密码，也不操作电源或键鼠。
